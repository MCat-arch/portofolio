Project 6: UD Tri Sakti

This project is aimed to display materials product and its stock from UD Tri Sakti shop.

Key Features:

  • Landing page for UD Tri Sakti
  • Display product based on the category
  • Display product detailed and provide WhatsApp contact so user can immediately connect with the shop for further information

Technologies Used:

  • Frontend: CSS, Bootstrap 5
  • Backend: Node Js
  • Database: MongoDB
  • Version Control: Git and GitHub

Project Goals:

  • Provide a proffesional landing page for the shop
  • Provide shop's contact and social media information to user
  • Give information about product available at the shop, and detailed information about the product including its stock
